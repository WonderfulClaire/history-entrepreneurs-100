## 收录原则

四条，全部硬性：

1. 在**真正不确定**的时刻做过关键决策——不是算过概率的赌，而是事后才能看清的对。
2. 相信了**同时代人大多不信**的事，并坚持到它兑现。
3. 靠**长期复利**把一次判断变成持续增长的生意或组织。
4. **决策/至暗/顺境/波折**四轴都有可考的细节（书信、传记、新闻、对手的记录）。

参考 *The Founders Report* 对"最伟大创始人"的归纳，并叠加本仓库四轴框架。
当前收录 56 位（截至 v2026.08），达标即入，宁缺毋滥。

## 四轴模板（每个条目长这样）

每个 `figures/<slug>.md` 统一下面 9 段，便于跨条目检索和对比：

| # | 段落 | 内容 |
|---|---|---|
| 1 | 一句话定位 | 他是谁、做成了什么 |
| 2 | 时代背景 | 他所处的约束条件 |
| 3 | 关键决策 | 在不确定时做了什么选择 |
| 4 | 至暗时刻 | 怎么扛过来的 |
| 5 | 顺境作为 | 走上坡路时怎么守、怎么扩张 |
| 6 | 人生波折 | 失败、背叛、起落 |
| 7 | 启示 | 可迁移的几条 |
| 8 | 推荐阅读 | 一本靠谱的传记 |
| 9 | 金句 | 他或后人总结的一句话 |

不要替换或省略段落——四轴框架比"完整传记"更有横向比较价值。

## 条目示例：Henry Ford

> 取自 `figures/henry-ford.md`，用于一眼看出本仓库的写法密度。

```markdown
# Henry Ford · 流水线让汽车普及

## 一句话定位
福特汽车创始人，用流水线 + 5 美元日薪重塑制造业，让汽车走入寻常家庭。

## 关键决策
- **只做一种车（Model T）、只黑一种色**：极致简化以砸低价格。
- **移动装配线（1913）**：把工时从 12 小时降到 90 分钟。
- **5 美元日薪（1914）**：让工人买得起自己造的车，制造中产消费者。

## 至暗时刻
- 早年 Detroit Automobile Company 等公司接连失败。
- 与持股人就控制权激烈争斗。

## 顺境作为
Model T 卖出 1500 万辆，福特成"量产"代名词；后建 Rouge 工厂做垂直整合。

## 人生波折
- **反犹立场**：办报社散布反犹言论，留下难以洗白的道德污点。
- 晚年与儿子埃德塞尔关系紧张、接班人问题混乱。

## 推荐阅读
- 《My Life and Work》（自传）
```

## 结构化数据 · `figures/index.json`

每份人物条目同步登记到 [`figures/index.json`](figures/index.json)，字段：

```jsonc
{
  "slug": "henry-ford",
  "name_zh": "亨利·福特",
  "name_en": "Henry Ford",
  "era": "1903",
  "region": "US",
  "industry": "manufacturing",
  "axis_decision": "流水线 + 5 美元日薪",
  "axis_dark": "早期公司接连失败 + 控制权之争",
  "axis_up": "Model T 1500 万辆 + 垂直整合",
  "axis_plot": "反犹立场污点 + 接班人问题"
}
```

工具读取 `index.json` 即可生成时间线、地理分布、行业分布等可视化，无需爬 markdown。

## 使用方式

```bash
git clone https://github.com/WonderfulClaire/history-entrepreneurs-100.git
cd history-entrepreneurs-100

# 系统读：从 figures/ 按时代/地区顺读
ls figures/

# 找某类启示：用 grep 在"启示"段里搜关键词
grep -ri "启示" figures/ | head

# 做工具：用 index.json（schema 见上节）
cat figures/index.json | jq '.[].region' | sort | uniq -c
```

## 贡献 & 许可证

- **PR 接受**：补人 / 补细节 / 纠错。
- **硬性条件**：四轴都有可考来源。**不达标不放进来。**
- 索引同步：新增人物请同时在 `figures/index.json` 与本 README 类别表登记。
- 引用规范：传记优先权威者撰写的版本（如《My Life and Work》《鞋狗》《富过三代》），少用营销号。
