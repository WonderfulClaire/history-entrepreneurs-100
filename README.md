# 历史上 100 位成功创业者 · history-entrepreneurs-100

> 以史为鉴。不是堆名人，而是讲清楚：**他们关键决策怎么做、至暗时刻怎么扛、顺境时怎么守、人生经历过哪些波折。** 一面给今天创业者的镜子。

---

## 为什么要做这个仓库

现在市面上的"成功经验"大多来自大厂中层、近期科技创始人——他们的分享未必多厉害，且高度同质。

但历史里有一群人：他们白手起家、穿越战争与萧条、被银行拒贷几百次、在所有人都不信时押注未来，最终留下跨越时代的生意与组织。**把他们放在今天，依然有借鉴意义。** 这正是"人类群星闪耀时"式的价值——有些东西是相通的。

所以这里不凑数、不求刚好 100。宁缺毋滥：**只收那些"决策—至暗—顺境—波折"叙事完整、今天仍能照见自身的人。** 够硬就收，慢慢补。

---

## 每个条目怎么读（四轴模板）

每个人物一份 `figures/<slug>.md`，统一结构：

1. **一句话定位** — 他是谁、做成了什么
2. **时代背景** — 他处在什么约束里
3. **关键决策** — 在不确定时，他做了什么选择
4. **至暗时刻** — 他怎么扛过来的
5. **顺境作为** — 走上坡路时，他怎么守、怎么扩张
6. **人生波折** — 那些失败、背叛、起落
7. **给今天创业者的启示** — 可迁移的几条
8. **推荐阅读** — 一本靠谱传记
9. **金句** — 他自己或后人总结的一句话

---

## 选材标准

借鉴 *The Founders Report* 对"最伟大创始人"的归纳，叠加本仓库的四轴：

- 在**真正不确定**的时刻做过关键决策（不是算过概率的赌）
- 相信了**同时代人大多不信**的事
- 靠**长期复利**把一次对未来的判断变成大生意
- 且"至暗 / 顺境 / 波折"有真实可考的细节

## 怎么用

- 想系统读：从 `figures/` 挑一个时代或地区顺下去。
- 想找某类启示：看每份末尾"给今天创业者的启示"。
